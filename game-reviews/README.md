# Co-op Reviews

Jelly and Jupiter's co-op game review site (Vue 3 + Vite, no backend), live at https://bettertogethergaming.com.

- `npm run dev`: start the dev server
- `npm run build`: build to `dist/` (plus the per-route SEO pages)

See `CLAUDE.md` for how the app, data and deploys fit together.
